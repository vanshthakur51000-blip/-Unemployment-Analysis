# Unemployment Analysis in India

## 📌 About Project

This project analyzes unemployment trends in India using Python and data visualization.

The analysis focuses on:
- Unemployment trends over time
- COVID-19 impact
- Region-wise unemployment
- Monthly unemployment patterns
- Labour participation

## 🛠️ Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- VS Code

## 📊 Dataset

**Unemployment in India** dataset from Kaggle.

## 🔍 Key Findings

- Average unemployment rate: **11.79%**
- April had the highest monthly average: **23.64%**
- Puducherry had the largest COVID-period increase: **22.14 percentage points**
- Labour participation and unemployment showed almost no linear correlation.
